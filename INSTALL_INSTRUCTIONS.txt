1. PROJECT OVERVIEW
================================================================================

This is a Flask web application for managing Users and Roles. It has TWO
equivalent versions that share the same UI:

- app.py = Uses SQLAlchemy ORM (Object-Relational Mapping)
- user.py = Uses Raw SQL queries

Both versions look identical and work the same way.

5. HOW TO INSTALL ON NEW COMPUTER
================================================================================

PREREQUISITES:
--------------
- Python 3.8 or higher
- PostgreSQL database
- Git

STEP-BY-STEP INSTALLATION:

Step 1: Clone the Repository
-----------------------------
git clone https://github.com/taskplete/base.git
cd base

Step 2: Create Virtual Environment
-----------------------------------
python -m venv venv

Step 3: Activate Virtual Environment
-------------------------------------
Windows:
  venv\Scripts\activate

Mac/Linux:
  source venv/bin/activate

Step 4: Install Dependencies
-----------------------------
pip install flask
pip install flask_sqlalchemy
pip install flask-login
pip install psycopg2-binary
pip install Flask-WTF

Step 5: Create Database
------------------------
Open PostgreSQL and run:
  CREATE DATABASE admin;

Step 6: Update Connection String (if needed)
---------------------------------------------
In app.py and user.py, find this line:
  postgresql://postgres:aothecode@127.0.0.1:5433/admin

Change port if your PostgreSQL uses different port:
  - Default port: 5432
  - Our port: 5433

Step 7: Apply Database Schema
------------------------------
Run database.sql in PostgreSQL:
  \i path/to/database.sql

Or manually copy/paste the SQL into pgAdmin.

Step 8: Run the Application
-----------------------------
ORM Version (port 5000):
  python app.py

Raw SQL Version (port 5001):
  python user.py

Step 9: Open Browser
---------------------
Go to: http://127.0.0.1:5000/login

Login with:
  Username: admin
  Password: admin123
