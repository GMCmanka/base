ORM Version (app.py)

python app.py

# Access:
http://127.0.0.1:5000/login

  • SQLAlchemy ORM models
  • Relationship queries (User.role)
  • App factory pattern
  • Flask-Login integration

# Run Raw SQL version (port 5001)

# Access:
http://127.0.0.1:5001/login
Features:
  • Raw SQL queries
  • Wrapper classes for compatibility
  • No ORM models

4. How to Install on New Computer

Prerequisites: Python 3.8+, PostgreSQL, Git
# Step 1: Clone the repository
git clone https://github.com/taskplete/base.git
cd base

# Step 2: Create virtual environment
python -m venv venv

# Step 3: Activate virtual environment
venv\Scripts\activate

# Step 4: Install dependencies
pip install flask flask_sqlalchemy flask-login psycopg2-binary Flask-WTF

# Step 5: Create database in PostgreSQL
CREATE DATABASE admin;

# Step 6: Apply database schema
# Copy/paste database.sql into pgAdmin

# Step 7: Run the application
python app.py

# Step 8: Open browser
http://127.0.0.1:5000/login

# Login: admin / admin123
